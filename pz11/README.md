# Тесты эндпоинтов

Из каталога проекта запустите:

```sh
docker compose -p duty-mvp-tests up --build --exit-code-from tests test-db test-app tests
```

Compose запускает отдельный экземпляр приложения и PostgreSQL с временным хранилищем. Тесты отправляют реальные HTTP-запросы внутри сети Compose. Обычное приложение доступно на `127.0.0.1:8000`, а тестовый экземпляр использует порт `8000` только внутри сети. Команда возвращает код завершения тестов и останавливает тестовые сервисы.

После запуска на хосте появится `test-results/results.json`. Каждый прогон перезаписывает файл, в том числе при падении тестов. В отчёте одна запись на HTTP-запрос. В ней есть имя теста, путь, HTTP-метод, ожидаемый и фактический коды ответа, результат проверки запроса (`result`) и результат всего тестового сценария (`test_result`). Если сервер не ответил, `http_status` равен `null`.

После прогона контейнеры можно удалить:

```sh
docker compose -p duty-mvp-tests --profile test down
```
